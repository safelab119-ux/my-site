# 사이트 설계도(PRD) — (미정: 사이트 이름)

작성일: 2026-10-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
기업 교육 담당자에게 업무·자기계발 출강 강의를 소개하고 강의 문의를 받는 사이트 (강의 세부 주제는 미정)

## 2. 손님
- 누가: 기업 교육 담당자 (HR·교육 담당)
- 어디서 알고 오나: 검색(네이버·구글), 블로그·SNS

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 강의 내용·커리큘럼 — 무엇을 배우고, 몇 시간·몇 회로 구성되는지
2. 강사 경력·실적 — 어떤 회사에서 강의했고, 어떤 경력이 있는지
3. 우리 회사에 맞춤 가능 여부 — 직원 수준·업종에 맞게 바꿀 수 있는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 강의한 회사·기관: 있음 — (미정: 공개해도 되는 이름은 만들 때 받는다)
- 경력·자격: 있음 — (미정: 내용은 만들 때 받는다)
- 강의 현장 사진: 있음 — (미정: 사진 파일은 만들 때 받는다)
- 후기: 있음 — (미정: 실제 후기 문장은 만들 때 받는다. 받기 전에는 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 강의 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 버튼(강의 문의하기)
2. 강의 내용·커리큘럼
3. 회사 맞춤 진행 방법
4. 강사 소개 — 경력·자격, 강의한 회사·기관
5. 강의 현장 사진
6. 후기 (실제 후기를 받기 전에는 비워 둠)
7. 문의 폼 + 다른 연락 방법

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 문의 내용 (자유롭게 — 인원·일정·원하는 주제)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 사이트에 금액을 적지 않는다. "문의 후 견적 안내"
- 시간: (미정)
- 위치: (미정 — 출강)
- 연락 방법: 문의 폼, 이메일, 카카오톡 채널, 전화번호 (실제 주소·번호는 만들 때 받는다)

## 9. 이번에 넣지 않을 것
- 결제
- 블로그·칼럼
- 강의 자료 내려받기
- 영어 페이지
- 회원가입·로그인

## 10. 첫 화면 한 문장 후보
1. 우리 회사에 맞춘 업무·자기계발 출강 강의
2. 직원들의 일하는 방식을 바꾸는 기업 맞춤 강의
3. 교육 담당자가 믿고 맡기는 업무 역량 강의

## 11. 다음에 할 것
- 9번 목록 (결제, 블로그·칼럼, 강의 자료 내려받기, 영어 페이지, 회원가입·로그인)
- 강의 세부 주제 정하기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함 (frontend-design 스킬 참고)
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel
- 검색 노출: 제목·설명 태그, 공유 미리보기(OG), sitemap.xml, robots.txt. /admin은 noindex

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 검색 노출 준비(태그·sitemap·robots)를 하고, 구글 서치 콘솔·네이버 서치어드바이저 등록 순서를 안내한다
5. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력, 검색 등록 사이트 로그인
